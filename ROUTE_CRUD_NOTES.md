# SmartTravel — маршрут (CRUD)

Реализация вкладки маршрута для текущего frontend-проекта. Все запросы обслуживаются MSW; подключение к backend не требуется.

## Проверка

1. Убедиться, что в `.env.development` установлено `VITE_USE_MOCKS=true`.
2. Запустить `npm run dev`.
3. Войти под тестовым пользователем `dasha@mail.ru`, пароль `secret123`.
4. Открыть поездку «Казань на выходные» и вкладку «Маршрут» (`/trips/t-1/route`).
5. Проверить добавление, редактирование и удаление пункта.

## Реализовано

- `GET /trips/:tripId/itinerary` — получение плоского списка пунктов, отсортированного по `day_date` и `position`.
- `POST /trips/:tripId/itinerary` — создание пункта.
- `PATCH /trips/:tripId/itinerary/:itemId` — изменение полей пункта.
- `DELETE /trips/:tripId/itinerary/:itemId` — удаление пункта с ответом 204.
- Проверки авторизации, участия в поездке и отсутствующего пункта в моках.
- Дни маршрута строятся по датам поездки; пустые дни также отображаются.
- Карта пока представлена макетной SVG-схемой из оригинального `Trip.dc.html` с подписью о будущей интеграции Leaflet.

## Границы задачи

Drag-and-drop и изменение `position` перетаскиванием не реализованы: это отдельная следующая задача. Поле `position` поддерживается API и моками, чтобы последующая реализация могла использовать тот же контракт.

Моки хранят состояние в памяти вкладки браузера; после полной перезагрузки страницы данные возвращаются к исходному тестовому набору.
